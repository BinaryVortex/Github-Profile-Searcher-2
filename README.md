# Github Profile Searcher 2

A simple, lightweight Github profile searcher built with plain HTML, CSS and JavaScript.

## Demo

Open `index.html` in your browser (or host the repo on GitHub Pages) and enter a GitHub username to fetch the user's public profile and repositories using the GitHub public API.

## Features

- Search for any GitHub user by username
- Display profile information (avatar, bio, location, followers, following, etc.)
- List public repositories with links
- Responsive, clean UI built with HTML/CSS

## Tech stack

- HTML
- CSS
- JavaScript

According to the repository statistics, this project is mainly written using CSS, JavaScript, and HTML.

## Installation / Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/BinaryVortex/Github-Profile-Searcher-2.git
   ```

2. Open `index.html` in your browser:

   - Double-click `index.html` or
   - Serve the folder with a simple HTTP server (optional):
     ```bash
     # Python 3
     python -m http.server 8000
     ```
     then visit `http://localhost:8000`.

3. Type a GitHub username into the search box and press Enter or click the search button.
